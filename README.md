# PhotoAllIsAI

**从大量照片中快速找到值得留下的画面，再把选片、整理、AI 生成和交付串成一条顺畅的工作流。**

PhotoAllIsAI 是面向摄影师、修图师和内容创作者的桌面图库。它把熟悉的文件夹工作方式与照片管理结合起来：关联现有目录即可浏览，不必先把原图搬进另一个库；在图库里完成筛选、评分和批量文件操作，也能从选中的照片直接创建 AI 任务、审阅生成版本并导出。

> **项目状态：持续开发中的可运行版本。** macOS 与 Windows 共用业务代码，已有对应打包配置。大规模真实图库、不同相机格式、Windows 实机安装运行以及正式签名发行仍在持续验证中；请把重要照片保留在自己的备份流程里。

## 适合怎样使用

1. **关联文件夹**：把已有拍摄目录加入侧栏，浏览原有目录树；关联操作只建立索引，不复制或改写原图。
2. **快速选片**：用网格、瀑布流、列表、分组、胶片带和看图页浏览；用星级、旗标、颜色标签、收藏、标签和搜索缩小范围。
3. **整理与交付**：多选后复制、移动、重命名或加入相册；把真实文件复制、粘贴、拖入和拖出；按预设批量导出原图或生成版本。
4. **需要时使用 AI**：配置模型服务，对照片做分析或按模板批量生成，比较候选版本，查看任务状态和失败原因，再决定交付哪些结果。

没有配置 AI 模型时，图库浏览、选片与本地文件整理仍可使用。AI 请求会把参与任务的图片发送到你选择的模型服务。

## 功能亮点

### 为连续看图和大量照片设计

- 支持临时打开文件、打开目录及关联文件夹；关联目录有索引、分页查询和文件变更同步。
- 网格、瀑布流、分组、列表和胶片带可以按工作习惯切换；看图页支持全屏、适应窗口、实际像素和相邻照片切换。
- 方向键可连续导航；多选支持范围选择和追加选择。图库缩略图尺寸可调，并会记住设置。
- 文件名与目录名使用自然顺序，例如 `导出2` 排在 `导出10` 前。
- 预览采用分尺寸缓存，后台生成可复用的缩略图与屏幕预览；按最近使用情况清理，并允许设置磁盘上限或手动清空可重建缓存。关联文件夹的右键菜单也能清理对应缓存。

### 像管理真实文件一样管理照片

- 关联文件夹保留原有磁盘组织；相册和智能集合提供不移动原文件的组织方式。
- 星级、旗标、颜色标签、收藏、标签以及 AI 记录保存在本地图库数据库，不写回原图或 XMP。
- 支持图库内批量复制、移动、重命名、移到系统回收站；文件操作有冲突处理、记录和相应恢复路径。
- 多选文件可复制到系统剪贴板，再粘贴到 Finder 或文件资源管理器；也可从外部粘贴文件或剪贴板图片。图库与外部程序之间支持拖入、拖出真实文件路径。具体系统集成仍需在各平台和目标程序中验证。
- 可在图库和文件夹之间拖放，并通过菜单执行对应的文件操作；相册只添加关联关系。

### 从选片走到 AI 版本与导出

- 对选中照片发起 AI 分析，查看描述和建议；可使用提示词模板、批次统一要求和单张补充要求创建生成任务。
- 任务中心保存队列、进度、失败信息和生成候选；支持重试失败项，并保留原图与生成版本的关系。
- 在看图页查看、比较版本，再通过导出预设批量输出。导出支持 JPEG、PNG 或原格式，并可设置质量与长边尺寸。
- 生成结果默认集中存放，也可选择保存在原图旁的便携目录。原图默认不被后台 AI 任务修改。
- 提供 Agent 工作区与受限应用工具，用于组合图库、分析和生成操作；相关能力仍在迭代，实际效果取决于所配置的服务。

## 格式与平台边界

常见 JPEG、PNG、WebP、GIF、AVIF、BMP、TIFF 等图片有浏览路径；RAW、HEIC/HEIF 的实际预览能力取决于系统解码支持和素材格式。RAW 预览在原生解码失败时可尝试系统已安装的 ImageMagick（`magick`）。TIFF 有内置解码路径。视频目前只覆盖**临时打开 MP4** 的基础播放；视频尚未纳入持久图库，其他封装格式的跨平台播放与缩略图不能视为已支持。

当前目标平台是 **macOS 和 Windows x64**。仓库包含对应打包命令，但构建产物不等同于签名、公证或所有设备上的兼容性验收。Linux 文件剪贴板有 GNOME/URI 列表适配代码，Linux 桌面发行不在当前交付范围内。

| 网格 / 列表 | `G` / `E` |

## 数据与隐私

- 图库索引、评分、标签、生成版本和任务信息保存在本机应用数据目录；关联目录中的原图仍保留在其原始位置。取消关联不会删除磁盘文件。
- 缩略图和预览位于可重建的本地缓存目录；清理缓存不会清理原图、生成结果或分析记录。
- 配置 AI 服务后，相关图片和提示词会发送给所选服务。API Key 保存于本机应用配置，并在系统安全存储可用时加密；请自行评估所用服务的隐私政策和费用。
- 应用提供图库备份、恢复和诊断入口；执行大批量文件整理前仍建议保留独立备份。

## 本地开发

需要 Node.js、[pnpm](https://pnpm.io/) 和相应平台的 Electron 构建环境。仓库声明的 pnpm 版本为 `10.12.4`。

```bash
corepack enable
pnpm install
pnpm dev
```

页面修改会热更新；主进程和预加载脚本修改会重建并重启 Electron。常用检查命令：

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm test:e2e
```

`pnpm test:e2e` 会先构建，再运行 Playwright 用例。真实素材测试需自行准备 `test_data` 并使用 `pnpm test:real-data` 或 `pnpm test:real-data:preview`；普通单测和构建不依赖私有照片库。

## 打包

```bash
pnpm package:dir  # 当前平台的未签名可运行目录
pnpm package:mac  # macOS x64 / arm64
pnpm package:win  # Windows x64
```

签名、公证和证书由发布环境注入，仓库不包含私钥。跨平台构建成功只能证明产物生成，正式发布还需要在对应系统上完成安装、运行、升级和卸载验证。
