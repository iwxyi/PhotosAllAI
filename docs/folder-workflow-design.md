# 文件夹流程视图：实施设计

> 2026-10-24。设计范围：与外部图片软件协作的动态流程浏览，不包含自动操控外部软件和图片编辑。
> 产品方向见 [轻量浏览器设计](lightweight-browser-design.md#80-流程资产同一张图的多阶段版本)。

## 配置与入口

- 设置新增“流程”分区，管理预设与全局默认；不混入模型服务配置。
- 图库工具栏提供流程入口，显示当前启用状态。弹窗针对当前文件夹或相册配置：继承、选择预设、自定义、关闭。
- 未选择文件夹或相册时，该入口管理全局默认。全局默认初始关闭，避免升级后改变已有列表。
- 子目录继承最近父目录显式配置；相册覆盖只影响相册视图。自定义复制当前规则，之后独立保存。
- 流程编辑器按步骤展开，字段为名称、正则、匹配字段（相对路径/文件名）、忽略大小写。命名捕获 `key` 必填，`variant` 与 `project` 可选。
- 相同项目内使用 `key` 关联；`project` 捕获用于拆分嵌套项目。跨导入根目录绝不自动合并。相册保留各成员的项目命名空间。
- 提供一套可编辑示例预设，不要求用户采用该目录结构。可添加、删除、排序步骤与复制预设。

## 匹配与呈现

1. 主进程读取实际目录相对路径，Renderer 不获得绝对路径。
2. 按配置作用域处理完整资源集合，再进行分页，不能只把当前加载的 200 张归组。
3. 每个文件最多归入一个阶段；多规则命中保留冲突状态，独立展示，不静默挑选。空关联键或未匹配文件也独立展示。
4. 同组多个阶段及同阶段候选全部保留。代表项选择最后一个存在且在线的配置阶段，再用稳定名称顺序选择候选。离线组仍可见。
5. 筛选先确定命中的组，组内阶段仍完整可查看；选中代表项的批量操作只作用于该代表文件，不暗中处理全组。
6. 保存配置前可预览归组数、匹配数、未匹配数、冲突数及带阶段的实际图片名称；无效正则阻止保存。
7. 正则在隔离执行环境中运行并限时，超时显示可理解的错误，不阻塞 Electron 主进程。

图库代表图只增加一个紧凑版本数量标记。看图增加阶段选择组，显示阶段名和同阶段候选；左右切图仍切换资产组，阶段按钮切换同一组的文件。不增加第二排全局标签或新的看图页面。普通图片和任务来源照常打开。

按规则推断的关系显示“按规则关联”，不伪造 Lightroom、像素蛋糕的处理参数。AI 候选属于分支，不能画成先后执行的链。任务记录与当前归组独立，改规则不修改历史。

## 持久化与变化

独立持久化流程配置，使用现有安全文件写入机制和 IPC 校验。配置只引用目录/相册 ID 和预设 ID。规则与归组不重命名、不移动、不修改图片。

复用已有目录同步机制，增加对外部新增、移除和改名的持续检查。合并短时间变化，写入文件稳定后再发布；在恢复焦点和手动刷新时校验。归组结果随目录更新重算。持久化配置变化通知所有使用方刷新。

## 验证

- 多阶段、不同扩展名、命名后缀、多个候选、未匹配、重复键和规则冲突。
- 两个项目中的同名图片不合并；相册配置不污染目录配置。
- 默认配置、父目录继承、自定义副本、关闭与恢复继承、重启持久化。
- 病态正则可中止，绝对路径不跨 IPC，批量操作范围不扩大。
- 超过一页的阶段文件仍正确聚合；外部新增文件后无需重启即可出现。
- 图库只显示代表图，双击看图可以切阶段与候选，Esc 恢复原列表；不同窗口尺寸不越界。

## 交付顺序

1. 规则契约、隔离匹配器、配置继承和预览服务。
2. 全局/局部配置界面、完整集合归组与图库代表项。
3. 页内看图阶段切换、目录更新联动。
4. 单元与 Electron 端到端验证、修复、同步实际交付状态。
