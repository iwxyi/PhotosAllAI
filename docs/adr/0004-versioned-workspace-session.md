# ADR-0004：工作区会话采用版本化本地状态

- 状态：accepted
- 日期：2026-09-19

## 决策

工作区会话由 Main 进程写入图库 SQLite 的 `application_state` 表。Renderer 仅通过经过共享 Schema 校验的 IPC 读取和防抖保存版本化状态，不直接使用 `localStorage` 作为真相来源。

第一版会话保存已打开标签、活动标签、图库文件夹、标签筛选、搜索文本和当前 Asset ID。它不保存本地文件路径、凭据、临时弹窗、活动文件事务或未提交的模型表单。

图库标签始终保持打开；功能标签可以关闭和重新打开。状态损坏、版本未知或跨版本校验失败时，应用回退到完整的默认工作区，不能阻止启动。

## 原因

会话状态需要随本地图库备份和迁移，且必须经过与其他 IPC 相同的运行时校验。稳定 Asset ID 能在原图移动或重命名后继续恢复选择，而保存路径会泄露目录信息并形成脆弱关联。

## 影响

- 后续新增缩放、面板尺寸和标签排序时必须追加 Schema 版本迁移。
- 高频状态在 Renderer 端合并后保存，Main 端使用单条 UPSERT 保证原子替换。
- 草稿和需要“是否放弃修改”语义的页面应另建持久草稿模型，不能混入普通会话快照。
