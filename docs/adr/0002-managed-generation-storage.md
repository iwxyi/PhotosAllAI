# ADR-0002：生成结果采用受管存储

- 状态：accepted
- 日期：2026-09-18

## 决策

AI 生成工作结果默认保存在程序管理的图库目录，原图文件夹不被后台任务修改。用户通过导出产生交付副本。原图旁 `_PhotoAllIsAI` 目录作为可选便携模式；任务记录实际策略，原图移动或重命名成功后幂等重定位对应 AI 子目录，失败时不覆盖目标内容。

删除生成版本采用应用内部回收站：文件移动到 `<library>/trash/generation/<result-id>/`，数据库保留版本、提示词、Provider 和原目标位置。恢复前检查目标冲突并且绝不覆盖现有文件；同卷使用原子移动，跨卷使用排他复制、大小与 SHA-256 校验，确认成功后才删除源文件。回收的版本不参与查看、导出、智能集合、批次清单或完整图库备份，版本序号也不复用。用户需要备份某个回收版本时应先恢复。

永久清理只能由用户在设置页显式发起并二次确认。服务仅接受严格位于 `<library>/trash/generation/<result-id>/<file-name>` 的普通文件；符号链接、目录、缺失身份或越界路径保护性跳过。清理先把确定性的同目录隔离路径写入数据库，再改名隔离、删除文件，最后删除数据库记录。应用启动和再次清理时会恢复已登记的清理意图，也兼容识别旧版严格命名的单个 UUID 隔离文件；原路径与隔离路径同时存在时保留两者并报告冲突，未知文件、多个候选、符号链接和越界路径都不推断或删除。没有清理意图且文件仅被外部移除的记录只在用户再次确认永久清理时删除，启动恢复保持不动。

生成结果写入采用独立持久化意图：先记录结果 ID、Asset、批次、存储模式、最终路径和排他临时路径，再写临时文件并原子发布，随后提交结果记录与 manifest，最后删除意图。启动时先完成原图文件事务并迁移相关便携意图，再回滚仍有意图的未完成结果并刷新 manifest；这保证任务可由队列重试而不会留下无记录的最终图片。恢复必须从当前 Asset 路径重新计算受管或便携目录并核对普通文件，符号链接、路径逃逸和不匹配记录保护性保留；便携目录迁移遇到新旧目录冲突时不改写意图路径，不猜测载荷归属。

## 原因

受管存储可以可靠维护多版本、任务恢复、回收站和数据库一致性，也适用于只读原图、外接盘和离线目录。

## 影响

应用必须提供图库迁移、备份提示、在文件管理器中显示和强大的批量导出。卸载不能默认删除图库。
