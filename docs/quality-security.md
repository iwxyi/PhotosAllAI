# 质量、安全与发布规范

## 1. 安全基线

### Electron

- `contextIsolation: true`、`sandbox: true`、`nodeIntegration: false`。
- preload 只暴露逐项白名单 API，不暴露通用 `invoke`、文件系统或 shell。
- 所有 IPC 请求在 Main 再次校验，不信任 Renderer 类型。
- CSP 禁止任意脚本执行；生产环境不加载远程 UI。
- 外部链接经允许协议检查后交给系统浏览器。
- 导航、新窗口、权限请求和下载默认拒绝，按用例开放。

### 凭据与网络

- API Key 使用 Keychain/Credential Manager，不进入数据库、日志、崩溃报告或导出清单。
- Provider Base URL 必须是 HTTPS；仅显式开发模式允许 localhost HTTP。
- 自定义 Header 名称和值分别校验，禁止覆盖安全关键 Header。
- 远端结果下载防护私网地址、协议跳转、无限重定向、超大响应和 MIME 欺骗。
- 日志默认对 Authorization、Cookie、查询密钥和用户目录做脱敏。

### 文件与图片

- 所有目标路径规范化并验证位于允许根目录内，防止路径穿越。
- 解码器在独立进程运行并设置资源限制，损坏图片不得拖垮 UI。
- 临时文件使用随机不可预测名称和限制权限。
- 覆盖、删除和跨卷移动均经过显式业务命令和事务日志。
- 清理任务只接受数据库解析出的具体文件，禁止以宽泛目录或未解析通配符为目标。

## 2. 测试规范

### 单元测试

覆盖领域不变量、状态机、文件命名、选择规则、模板变量和错误分类。测试不依赖网络与真实时间。

### 契约测试

共享 Schema 的有效/无效样本都需测试。Provider 使用本地模拟服务覆盖同步、异步、URL、Base64、限流、超时和畸形响应。

### 文件集成测试

每项文件操作在临时目录中测试正常、冲突、只读、磁盘空间模拟、跨目录、关联文件和中途失败。测试不得触碰用户真实目录。

### UI 与 E2E

- 组件测试覆盖键盘、焦点、ARIA、长文本和所有业务状态。
- Playwright 驱动打包或开发版 Electron 完成关键闭环。
- 视觉回归固定字体、DPI、主题、窗口尺寸和模拟数据。
- 动效通过最终稳定帧截图与必要的时序断言验证，不依赖肉眼一次性判断。

## 3. 性能门槛

性能场景使用固定数据集和硬件档位记录，不以开发机主观感受代替：

- 冷/热启动时间。
- 首批缩略图和首张预览可见时间。
- 10,000/100,000 资源的查询、筛选和选择时间。
- 连续切换 500 张照片后的内存峰值与回落。
- 后台分析/生成期间的滚动帧率。
- RAW 首屏、完整解码和 100% 查看耗时。
- 1,000 个任务恢复和队列编辑耗时。

性能退化超过已建立基线的 15% 时阻止发布，除非记录原因并批准。

## 4. 可访问性

- 核心工作流可完全使用键盘。
- 焦点顺序稳定，焦点样式不能被主题移除。
- 状态不只依赖颜色表达。
- 支持减少动态效果和 200% 系统缩放。
- 图标按钮具有可访问名称和工具提示。
- 自动化扫描之外，发布候选执行一次键盘人工走查。

## 5. 发布门禁

发布候选必须：

- 工作树干净且版本来自 Git tag。
- 类型检查、lint、单元、契约、集成、E2E 和构建通过。
- 数据库从前两个已发布版本升级成功，并验证失败回滚。
- 安装包签名验证通过，不含测试密钥和开发 URL。
- 凭据、日志和诊断包完成泄漏扫描。
- macOS arm64/x64 与 Windows x64 冒烟通过。
- 已知问题按严重度归档；数据丢失、安全和核心流程阻断问题必须为零。

## 6. 故障等级

| 等级 | 定义 | 发布策略 |
| --- | --- | --- |
| S0 | 数据丢失、凭据泄漏、任意代码执行 | 立即停止发布 |
| S1 | 核心流程不可用、结果错误关联、无法恢复 | 阻止发布 |
| S2 | 有替代路径的主要功能缺陷或明显性能回退 | 默认阻止，需明确批准 |
| S3 | 局部视觉、文案或低频问题 | 可带记录发布 |
