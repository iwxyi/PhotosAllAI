# 专业浏览器发布完善

> 本文的“本轮验证记录”是当时的历史快照，不代表 2026-11-03 的重测。当前范围、性能预算和待办见[大量图片浏览与批量生成路线图](browsing-batch-generation-roadmap.md)。

## 目标

轻量图片浏览器与 AI 批量任务共用文件、版本和选择上下文。主画面保持简洁，低频能力放入菜单与详情。不得把预览放大当作原始像素查看，不得把自动化通过等同于正式发行通过。

## 本轮交付与验收

- 系统打开：文件菜单、Finder 文件打开事件、第二实例参数、拖放；临时浏览同目录图片，不自动关联目录。
- 显示准确性：适应窗口、真实 100%、适应宽度、围绕鼠标缩放、边界约束；浏览器原生支持的图片直接解码原文件，RAW 等使用明确标识的预览。
- 查看工具：透明背景切换、全屏；无可比较版本时不展示无效比较与导出入口。
- 详情：真实文件路径、大小、修改时间、尺寸和可用拍摄参数；真实分析与生成版本，错误可见。
- 外部协作：打开原文件、定位文件、复制路径；返回窗口继续触发既有目录刷新。
- 回归：既有选择、输入框快捷键、原位退出、流程切换、任务与文件操作不得退化。

## 后续独立验收

- 任意两图参考比较、相似图人工复核、保存复合筛选、批量格式转换。
- RAW 全尺寸解码、各系统 ICC/HDR 一致性与动画格式专项矩阵。
- 100,000 图片性能、长时间浏览内存、后台解码资源限制。

上述能力没有完成验证前不得在产品中宣称支持。公开格式支持应区分原图查看、系统解码预览与不支持。

## 发布门禁

遵循 `quality-security.md`：类型、lint、完整单元与集成、E2E、生产构建、安装包检查。macOS 签名/公证和 Windows 实机检查需要真实发行环境；未完成的门禁必须在交付报告中列明。不得自动提交用户既有变更或发布安装包。
